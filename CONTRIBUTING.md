# Contributing

## Suggested workflow

1. Create a branch for each task or feature.
2. Keep pull requests focused and small.
3. Add or update tests when behavior changes.
4. Document important decisions in `docs/`.

## Team folders

- `src/` for application code
- `tests/` for test coverage
- `docs/` for notes, plans, and decisions
- `assets/` for shared files
- `scripts/` for setup and utility scripts
