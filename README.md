# Snack_Automat


## Project layout

```text
Snack_Automat/
|- assets/             Shared images, icons, and other static files
|- docs/               Planning and collaboration notes
|- scripts/            Helper scripts for setup or automation
|- src/                Main project code
|- tests/              Test files
|- CONTRIBUTING.md     Team workflow and collaboration guide
|- README.md           Project overview
```

## Getting started

1. Put application code in `src/`.
2. Add tests in `tests/`.
3. Track planning notes and decisions in `docs/`.
4. Use `assets/` for shared static resources.
5. Add reusable helper scripts in `scripts/`.
